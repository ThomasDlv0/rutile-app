**Rutile 1.3.1** ouvre la roue Actions sur ce qui convient au fichier secoué, et laisse ranger les parts de la roue Actions dans l'ordre de votre choix.

## Nouveautés

- **Roue Actions d'un fichier** : un fichier secoué, glissé sur la roue ou sélectionné dans le
  Finder ou l'Explorateur ouvre une roue réduite à ce qui a un sens pour lui. Deux documents
  proposent un ZIP, deux PDF leur fusion, une archive son extraction.
- **Roue ouverte d'abord, par type de fichier** : images, vidéos, PDF, archives et autres
  fichiers ont chacun leur réglage (Réglages → Actions → Selon le fichier). Par défaut, le
  convertisseur reste le premier pour les images et les vidéos, la roue Actions pour le reste.
- **Ordre des parts** : les parts de la roue Actions, les actions proposées pour chaque type de
  fichier et celles de vos roues se réordonnent en les glissant, et chaque part s'affiche ou se
  masque.
- **Nouvelles actions** : extraire une archive ZIP, copier le texte d'un PDF, copier le texte
  d'une image, copier une image dans le presse-papiers, copier le chemin des fichiers.
- **Mes roues** : une roue peut être réservée à certaines extensions (`pdf`, `docx`…).

## À savoir

- **Extraction** : l'archive se décompresse à côté d'elle, dans un dossier à son nom, ou sous
  le nom de son dossier si elle n'en contient qu'un. Rien n'est écrasé, et un nom piégé ne peut
  pas écrire hors de ce dossier.
- **Texte d'un PDF** : un PDF scanné n'a pas de texte à copier.
- **macOS** : Rutile n'ayant pas de certificat Apple, macOS peut oublier les autorisations
  Enregistrement de l'écran et Accessibilité après la mise à jour : retirez Rutile de la liste
  avec « − », puis autorisez-le de nouveau.

## Fichiers

| Système | Fichier |
|---|---|
| macOS 12+ (Apple Silicon et Intel) | `Rutile_1.3.1_macos_universal.dmg` |
| Windows 10 et 11 (x64) | `Rutile_1.3.1_windows_x64_setup.exe` (recommandé) ou `.msi` |
| Linux x64 | `Rutile_1.3.1_linux_x86_64.AppImage` (recommandé, Bazzite compris), `.deb` ou `.rpm` |

`SHA256SUMS.txt` donne l'empreinte de chaque fichier. `latest.json` et
`Rutile_1.3.1_macos_universal.app.tar.gz` servent aux mises à jour automatiques : inutile de les
télécharger.

## Avertissements d'installation

Rutile n'est pas signé avec un certificat Apple ou Microsoft :

- **macOS** : si macOS dit que l'app est endommagée ou ne peut pas être vérifiée, lancer
  `xattr -dr com.apple.quarantine /Applications/Rutile.app`, ou Réglages Système →
  Confidentialité et sécurité → « Ouvrir quand même ».
- **Windows** : SmartScreen → « Informations complémentaires » → « Exécuter quand même ».
- **Linux** : `chmod +x Rutile_1.3.1_linux_x86_64.AppImage`. Sous GNOME Wayland, le raccourci
  global se règle dans les paramètres du système (commande `rutile --open`), et le secouage
  demande le groupe `input`.

FFmpeg (GPL v3) est inclus sous le nom `rutile-ffmpeg` ; voir `THIRD_PARTY_LICENSES.md`.
